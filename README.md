# 🧠 Sistema de Bem-Estar Escolar - SIMPLES E COMPLETO

## 📌 O que é?

Um **sistema educacional em UM único arquivo** que demonstra **CONCEITOS FUNDAMENTAIS DE OOP**:

✅ **Herança** - Todas as classes herdam de `User`
✅ **Encapsulamento** - Propriedades privadas com `#`
✅ **Polimorfismo** - Método `getPermissions()` sobrescrito
✅ **Tratamento de Erros** - Robusto e seguro
✅ **SEM Banco de Dados** - Dados em memória
✅ **~400 linhas** - Código simples e direto

---

## 🚀 COMO RODAR?

### ⚡ Opção 1: ONLINE (SEM instalar nada!) - **RECOMENDADO**

1. Acesse https://repl.it
2. Clique em **"Create"**
3. Escolha **"Node.js"**
4. Cole o código de `backend/src/sistema-completo.js`
5. Clique em **"Run"**

**Pronto! 🎉 Veja a saída no console!**

### 💻 Opção 2: SEU COMPUTADOR (Com Terminal)

1. Instale Node.js: https://nodejs.org/
2. Clone o repositório
3. Entre na pasta:
```bash
cd backend
npm install
npm start
